# Next.js React Foundations - Learning Journey

A structured collection of my progress through the **official Next.js React Foundations** guide. Each chapter is organized in its own directory to track learning step by step.

## 📚 About

This repository documents my hands-on practice while working through the [Next.js React Foundations course](https://nextjs.org/learn/react-foundations). The goal is to build a solid understanding of React fundamentals before diving into Next.js.


## 🚀 Running a Chapter

Each chapter is self-contained. To run one:

```bash
cd chapter-XX
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
